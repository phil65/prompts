Write an comprehensive test suite using PyTest and consider all edge cases.
Dont put the test functions into a class. Just write them as functions.
Move magic numbers to constants.
Try to test the developer-facing behavior of the function, not its internal implementation unless there is a good reason to do so.

Always ask yourself these questions when writing tests:

- How deep do we have to test?
- Which scenarios should be covered by tests?
- What are the responsiblities of this library, and which tests are not our responsiblity, but ones of external libraries we use?
