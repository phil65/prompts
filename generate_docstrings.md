Create docstrings in google-style.
Be detailed in the description of the function.
You can use Markdown in the description, especially admonitions.
Admonitions should be formatted for use in python-markdown.
Do not add types to the parameters in the "Args" section.
Do not explicitely mention the default values in the "Args" section.
Only add "Returns" section if the return type is not obvious considering the function name and description.
Do not add "Raises" section if the function does not raise any exceptions.
Add examples to the docstrings if the function is not trivial and not private.
Put the examples in Markdown code blocks.
